# The Long Roast: Lawmakers and the File They Cannot Convert

A make.fun bounty entry — one satirical sentence (program/v1).

> "They voted 412-3 to regulate artificial intelligence, then spent the afternoon Googling 'how to PDF' on the machine they just voted to regulate."

`main.py` writes that sentence — exactly 144 characters, one sentence, no trailing newline — to `/output/entry.txt`. Deterministic, no network, no secrets.
